# TALIS transportation research website

Public website for Angela Kitali’s research group at the University of Washington, Tacoma Campus.

Website: https://bokanglifsu.github.io/transportation-ai-lab/

This repository contains the generated static website. GitHub Pages serves the main branch at its root. HTML pages and assets use relative links so the site can be moved to another host.

Content is maintained in the separate website workspace and exported here after building and checking. To update, replace the generated pages and assets together. Do not edit only one copy of a repeated header or footer. Private project materials, credentials and unpublished source documents do not belong in this repository.

Sources, image credits and publication links are provided on the website. Third-party images retain their original licenses. No blanket license is granted to third-party material.
